Frequently Asked Questions

Quick answers about using the toolkit.

How does the word counter work?

It splits non-empty text at whitespace boundaries to estimate the number of words. Results can vary for some languages and special formats.

Is WordCount Pro free to use?

This version is a free, browser-based tool. It does not require an account to use its included features.

Is my text uploaded anywhere?

The included text analysis and editing tools run locally in your browser. This page does not contain code to upload your text to a server.

Can I download my edited text?

Yes. Use the download buttons to save text as a plain .txt file on your device.

How is reading time calculated?

Reading time is estimated at 200 words per minute. Speaking time uses an estimate of 130 words per minute. Actual time varies by person and content.
